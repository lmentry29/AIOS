# Support

AIOS is an early-stage open-source project maintained on a best-effort basis. There is no paid support or response-time guarantee.

- **Questions and usage help:** open a GitHub Discussion if enabled, otherwise use a clearly titled issue with the `question` label.
- **Bug reports:** open an issue with reproduction steps, expected behavior, actual behavior, operating system, Node.js and pnpm versions, and the commit you are using.
- **Feature proposals:** describe the user problem first, then the proposed solution and alternatives.
- **Security issues:** follow [SECURITY.md](SECURITY.md); do not post vulnerabilities publicly.

Before opening an issue, search existing issues and read the current limitations in [README.md](README.md). Please do not post secrets, API keys, customer data, or private logs.
