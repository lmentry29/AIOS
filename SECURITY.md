# Security Policy

AIOS is experimental software. Do not use it to make consequential decisions, grant access, execute untrusted code, or process sensitive production data without an independent security review and controls appropriate to your environment.

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in public issues.

Use GitHub's **Report a vulnerability** feature in the repository's Security tab if it is enabled. If it is unavailable, contact the repository owner through the email or contact method listed on the GitHub profile. Include:
- A concise description and potential impact.
- Affected versions, commits, packages, and configuration.
- Reproduction steps or a minimal proof of concept.
- Any suggested mitigation.

Do not include real secrets, personal data, or third-party data in the report.

## Response expectations

This is a maintainer-led project with no dedicated security response team or guaranteed response SLA yet. The maintainer will acknowledge reports as capacity permits, assess severity, coordinate a fix, and determine an appropriate disclosure timeline. Please allow reasonable time for a fix before public disclosure.

## Scope

Report vulnerabilities in code maintained in this repository. Issues in third-party dependencies should also be reported to the relevant upstream maintainers.
