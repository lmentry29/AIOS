# AIOS Architecture Decision Records — Index

Phase 8 output. Resolves the six architectural open questions left unclosed by *AIOS-Documentation-Roadmap.md* (Priority 0, items 4, 5, 6, 7, 8, 13).

All six ADRs were amended 2026-07-09 to incorporate explicit founder decisions (layer count corrected to 10; Founder Intelligence confirmed cross-cutting, not a layer; Amendment 001 mechanism formally deprecated).

**Update (2026-11-10, blueprint v1.1):** ADR-0015 is now Accepted on implemented, tested evidence. ADR-0016 and ADR-0019 ratify the trusted host boundary and the fixed local-execution/verifier contract. ADR-0021 extends that contract with authorized cancellation, a configured concurrency cap, and startup reconciliation for per-Task executions. ADR-0022 adds deliberate, authorized resume/retry as append-only execution attempts; it amends ADR-0021's retry consequence without changing terminal cancellation. ADR-0017 and ADR-0018 record open prerequisites for Mission and infrastructure; ADR-0020 records release identity and distribution. ADR-0023 adds an authenticated, human-only runtime policy-publication path guarded by exact `administer_policy` grants, while retaining the offline bootstrap CLI. ADR-0024 adds authorized runtime retirement: an exact `revoke_policy` grant on every resource that references a version retires it, with fallback to the newest remaining version or a fail-closed deny when none remains. ADR-0012 remains Proposed: the first slice uses only fixed `local.exec`, so no general capability/provider selection is implemented. ADR-0029 adds the durable session lifecycle; ADR-0030 adds the human-only operator administration and CLI surface over it.

**Update (2026-07-10, repository initialization):** ADR-0007, ADR-0008, and ADR-0009 added, ratifying the Canonical Object Model, the canonical implementation language, and the repository/workspace organization respectively. ADR-0003 upgraded from Proposed to Accepted at the same time — see its own Status section for why. All six items listed below under "Still open after this batch" were in fact closed during the corpus reconciliation that followed this index's original creation; see `docs/process/reconciliation-changelog.md` and the Resolution Status table in `docs/archive/documentation-roadmap.md` for the full record. That section is left below unedited, as the historical record of what was still open at the time this index was written.
